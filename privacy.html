JK Shorts 개인정보처리방침

시행일: 2026년 11월 20일

JK Shorts는 사용자의 PC에서만 실행되는 프로그램입니다. 만든 사람은 서버를 운영하지 않으며, 사용자의 Google 계정 정보나 유튜브 데이터를 받지 않습니다.

1. 프로그램이 다루는 정보

  • Google 로그인 정보: 채널을 연결하면 Google이 내준 접근 토큰과, 연결한 채널의 이름·핸들·채널 ID가 사용자 PC의 사용자 폴더에 저장됩니다. 비밀번호는 프로그램에 전달되지 않습니다.
  • 유튜브 데이터: 사용자가 올리는 영상과 제목·설명, 올린 영상에 다는 댓글, 중복 업로드를 막기 위해 읽는 자기 채널의 최근 영상 목록.

2. 쓰는 목적

위 정보는 사용자가 연결한 채널에 영상을 올리고, 예약 공개하고, 댓글을 다는 데에만 씁니다. 광고나 분석에 쓰지 않습니다.

3. 저장과 전송

  • 토큰과 채널 정보는 사용자의 PC에만 저장됩니다. 만든 사람이나 다른 사용자에게 전송되지 않습니다.
  • 유튜브 데이터는 사용자의 PC와 Google(YouTube API) 사이에서만 오갑니다.
  • 사용자가 자신의 키로 선택 기능을 켠 경우, 사용자가 입력한 주제와 영상 내용이 해당 서비스(AI 작성: Anthropic, 내레이션 음성: Google Cloud)로 전송됩니다. Google 계정 정보는 여기에 포함되지 않습니다.
  • "함께 보는 영상 목록" 기능을 켠 경우, 공개 유튜브 영상의 후보 목록(영상 ID·제목·그 영상의 채널 이름·게시일·길이·찾을 때 쓴 검색어·승인 여부와 정한 구성원)이 사용자가 설정한 저장소에 올라갑니다. 사용자의 Google 계정 정보와 연결한 채널 정보는 올라가지 않습니다.

4. 보관과 삭제

  • 토큰은 사용자가 연결을 끊거나 PC에서 저장 파일을 지울 때까지 보관됩니다.
  • 권한은 Google 계정의 서드 파티 액세스 설정에서 언제든지 취소할 수 있습니다.

5. YouTube API 서비스

이 프로그램은 YouTube API 서비스를 사용합니다. 프로그램을 쓰면 YouTube 서비스 약관에 동의하는 것이며, Google이 정보를 다루는 방식은 Google 개인정보처리방침을 따릅니다.
